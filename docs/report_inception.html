ATCO shortage study

Inception Report · Page 6

The goal of this section is to provide a network-wide historical overview of ATCO shortages, including the current status, a comprehensive root-cause analysis, and an assessment of the impacts on local and network performance. This descriptive analysis establishes a baseline and provides overall context for subsequent discussions. This section will also explain different ways of approaching the topic (e.g., number of licence holders, headcount, FTEs, etc.).

Stakeholder mapping

Inception Report · Page 8

Stakeholder management begins by identifying all relevant groups and entities that could be affected by the changes. Once all stakeholders are identified and arranged in homogenous stakeholder groups, the resulting structure can be used to define the requir ed actions and specify various tools and channels to be used for engaging with each group.
