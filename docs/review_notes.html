Review notes

Coverage gaps and source issues found while assembling the prototype. The study text remains as supplied.

Portfolio sequencing and evaluation

The Final Report explains how measures complement one another and prioritises candidate recommendations. It does not set out tested intervention portfolios, local sequencing or quantified combined effects. The topic uses the existing passages; no portfolio design or scores have been added.

Monitoring arrangements

The logical model and Final Report describe post-operations feedback and candidate monitoring measures. A practical monitoring plan with agreed indicators, owners, thresholds and review dates would require additional material.

CBL implementation and worked cases

The clean Final Report supplies the proposal, rationale and next steps. The workshop comparison between similar ACCs is illustrative. A validated transition plan, assessment criteria and evidence of operational transferability are not supplied by these excerpts.

COOPANS EXODUS case

The Intermediate Report names COOPANS EXODUS and leaves its subsection for completion after interviews. No cleared standalone case narrative was identified in the material used for the prototype. The page preserves the report’s status.

Responsibilities for individual audiences

The report groups recommendations into ANSP, governance and technical perspectives. The four audience views reuse relevant passages. An agreed allocation of individual recommendations to the Commission, EASA, NSAs, NCAs and professional groups would require an editorial decision.

Common expected baseline

The Atlas structure considered a common expected baseline as an additional catalogue view. Its scope and criteria were not agreed. The three source perspectives are available; an additional baseline has not been defined.

The challenges and solutions catalogue

Model editions and the dashboard

The Intermediate Report’s earlier outlook extends to 2040; the clean Final Report’s operational workforce model runs to 2036. The Final Report’s objectives section also refers to a 2040 study horizon. Keep these scope statements and the model assumptions and outputs distinct. The prototype includes report figures, variables and sensitivity tables. The Power BI dashboard remains a separate study artefact; integrating or reproducing live calculation would require a decision about the approved model and hosting approach.

Publication copies for the Library

Report and presentation records contain attributed excerpts. The download collection contains extracts of report tables and the baseline reference register. The full report, presentation and model files need approved publication copies before they can be offered as downloads. The raw interview annex and collection log are excluded; the prototype uses report-level aggregate consultation findings.

Survey response bases

The Final Report records 26 participating ANSPs. Several question tables use a smaller or question-specific response base. The prototype preserves the supplied question text, counts and ratios. A publication edit should clarify denominators where the report does not state them explicitly.

Cross-references and bibliography

Some table and figure numbers are reused in the clean report. The prototype identifies them by source section and original caption. Performance Review numbering is inconsistent in the baseline report, and the later future-proofing chapter names sources absent from the earlier grouped register. Verify the final reference register against the approved report before publication.

Sector-specific training identifiers use TL-ST in the chapter tables and TL_ST in Annex J. Both spellings are reproduced as printed. A normalised link key joins the two locations for navigation; source identifiers and assessments have not been changed.
